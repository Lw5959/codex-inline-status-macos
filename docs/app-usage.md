# GPT 启动助手 2.1.4（纯原生）

适用于 Apple Silicon Mac、macOS 14+。不内嵌 Node 或 Python，也无需另行安装。

1. 打开 2.1.4 DMG，把 `GPT Launcher.app` 拖入 `Applications`，再双击打开。
2. 点击「检测 GPT 出口」。只有美国出口和美国时区同时核实通过，才能从助手启动或加载。
3. 首次使用需正常退出已有 ChatGPT（⌘Q），再点击「启动 ChatGPT 并加载状态条」。经本工具启动的现有进程升级后可点「连接现有窗口」，核验通道及实际时区后继续使用。
4. 从菜单栏使用助手，不要再把助手另固定到 Dock。默认窗口约 720×615，保留原字号，长提示可滚动。

非美国、检测失败或无法核实时均提示并禁止。手动改成纽约、旧的美国缓存都不能绕过；加拿大、墨西哥等 America 时区不按美国处理。

状态条每 5 秒采样；有新正文时更新速度，暂停、思考、工具执行和下一轮等待期间保留最近一次有效读数，不归零。完成后显示最近一段回复的速度，无有效样本时显示破折号。缓存命中率按真实累计数据更新。

动效默认开启，横线与数字双向切换、数字变化时均上下过渡约 700 毫秒；位数变化时宽度也平滑过渡，单位不会瞬间跳动。动画使用位移、透明度与静态模糊叠层，相同数字不重播；系统“减少动态效果”开启时关闭动效。图标间距为 3px，字号不变。

本会话已确认的回复速度、缓存命中率和保存时间会写入 `~/Library/Application Support/CodexInlineStatus/var/conversations/`，重开会话或后台重启后恢复。恢复值的悬浮说明标为「上次保存」，新输出独立采样。每 5 秒合并保存，同值不重复写盘；尚未确认的正文不覆盖已保存速度。不保存聊天正文或认证信息，损坏或属于另一会话的文件不采用。

切换会话再返回时，会直接回显该会话上次显示的速度和缓存命中率，不等待下一次 5 秒刷新。展示快照另存于本插件专用的本地页面存储，页面重建或超过 32 个会话后也可按 UUID 恢复；尚未完成的采样会注明历史来源及未完成核对，不继承其计时状态。离开会话中止后续计量，已发生的采样区间仍可回显；后续出现正文冲突等实质失效证据时撤销相应显示快照。

出口来自 GPT 同域回显，再按这个明确 IP 查时区；检测和新启动的 ChatGPT 共用原生转发进程，不依赖 Clash。动态出口池仍不能证明每条后续模型请求的实际源 IP，请使用稳定节点。

助手不会自动退出当前 ChatGPT，不修改系统时区、系统代理或官方应用。包使用本地签名，未 Apple 公证。旧版 2.0 安装包仍带运行时，请使用本次 2.1.4 包。升级后可点击「连接现有窗口」：原通道、重新检测的美国出口及真实运行时区都能核实一致时，可直接连接。只有未开启接入端口、通道或时区不匹配时才需要正常退出后重启。
